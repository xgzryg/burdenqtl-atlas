# Aortic aneurysm — portal data package

273,285 SNP associations with P < 1e-05. Beta, standard error and P values from the current study summaries are retained; lead membership is recorded separately. Beta CAF is expressed per 0.01 increase in country REF allele frequency at SDI=0. Observation counts refer to country-year records.

6 measure-by-sex groups, 273,285 association records, 112,580 distinct variants.

Each analysis TSV contains the released association fields and preserves their original source values. Empty gene, credible_status and causal_status cells mean not available; they are not negative findings. The portal display uses numeric/null values and retains zero P values. No model fitting, statistical correction, or LD clumping is performed by this build.

Choose a disease, burden measure and sex on the Results page to explore the collection. Filtered exports retain the identity of each association. GBD burden values are age-standardized rates per 100,000 for 1990–2023; variant coordinates use GRCh38. Country allele frequencies are derived from 1000 Genomes.

Statistical definitions and transformations are documented in the [statistical methods](S3C_P_value_transformation_disclosure.md).

The website and listed data downloads are publicly available at https://xgzryg.github.io/burdenqtl-atlas/. The research analysis code is available from the corresponding author upon reasonable request.
